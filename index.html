02 / RESEARCH

科研项目

012025.06–2025.12

多模态文旅推荐系统

研究问题
如何让文旅推荐系统利用领域知识，同时理解用户提供的文本和图片？
技术路线
以 InternLM-XComposer2 为基础，通过 QA-LoRA 做领域适配，并用知识图谱与 GraphRAG 增强检索。
项目成果
实现文本问答、图像识别和个性化推荐，并与原始模型和通用大模型进行对比。
  • InternLM-XComposer2
  • QA-LoRA
  • GraphRAG
022025.01–2025.05

电力运检知识图谱问答

研究问题
如何把分散的设备、缺陷和巡检记录组织起来，支持运检人员查询？
技术路线
按电力运检本体建模，在 Neo4j 存储实体关系，并结合向量检索与本地大模型回答问题。
项目成果
使用 Flask 和 Vue 3 构建交互页面，提供知识检索、问答和图谱可视化。
  • Neo4j
  • Vector search
  • Flask
  • Vue 3
032024.08–2024.12

复杂海陆场景小目标检测

研究问题
远距离目标在画面中尺寸小、特征弱，容易受到复杂背景干扰。
技术路线
对比 YOLOv8、YOLOv11 与 RT-DETR，实验覆盖高分辨率输入、数据增强和训练参数调优。
项目成果
调优后的 RT-DETR 在测试集取得 0.408 mAP50。
  • YOLOv8
  • YOLOv11
  • RT-DETR
